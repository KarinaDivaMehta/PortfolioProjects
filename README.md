# PortfolioProjects

SQL-based data projects.

## Projects

- **[covid-data-exploration](covid-data-exploration/)** — exploratory SQL analysis of COVID-19 case/death data across countries, comparing infection and death rates while controlling for population size. See its [README](covid-data-exploration/README.md) for findings.
- **[nashville-housing-cleaning](nashville-housing-cleaning/)** — SQL data-cleaning workflow on a raw Nashville housing dataset (`data/nashville_housing_raw.xlsx`): standardizing formats, splitting address fields, handling nulls, and removing duplicates.

## Setup

Both projects target SQL Server (T-SQL syntax). Import the relevant dataset into a local SQL Server instance, then run the corresponding `.sql` script.
